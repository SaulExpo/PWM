## 1. Cómo usar el proyecto

1. Tener instalado **NodeJS**.
2. Después de abrir el proyecto con **WebStorm**, ir a la consola de comandos y escribir: cd .\Strapi\my-project
3. Luego, escibir npm install
4. Escribir npm run develop
5. Una vez arrancado el strapi se puede acceder por medio de la siguiente URL a el admin para poder visualizar las tablas de donde salen los JSON: http://localhost:1337
6. Un ejemplo de un JSON en concreto sería el siguiente http://localhost:1337/api/Films (para ver los otros cambiar el Films por otras categorias tipo app-users, reviews o actors)
